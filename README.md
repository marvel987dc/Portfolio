# Juan Barrero Portfolio

Personal portfolio built with Astro and static output. The page keeps the original portfolio sections: introduction, skills, projects, about, contact, and footer.

## Development

```sh
npm install
npm run dev
```

## Build and preview

```sh
npm run build
npm run preview
```

The production site is generated in `dist/`. Node 22.12 or newer is selected with `.nvmrc` for local and Netlify builds.
